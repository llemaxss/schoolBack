# Environment variables

| Variable                | YAML key                     | Default value | Description    |
|-------------------------|------------------------------|---------------|----------------|
| `ACTIVE_PROFILE`        | `spring.profiles.active`     | `DEV`         | Active profile |
| `DB_HOST`               | `spring.datasource.url`      |               | DB host        |
| `DB_PORT`               | `spring.datasource.url`      |               | DB port        |
| `DB_NAME`               | `spring.datasource.url`      |               | DB name        |
| `DB_USERNAME`           | `spring.datasource.username` |               | DB username    |
| `DB_PASSWORD`           | `spring.datasource.password` |               | DB password    |
| `SERVER_PORT`           | `server.port`                |               | Server port    |
| `JWT_SECRET`            | `app.jwt-secret`             |               | JWT secret key |
| `JWT_EXPIRATION_MILLIS` | `app.jwt-expiration-millis`  |               | JWT TTL, ms    |
