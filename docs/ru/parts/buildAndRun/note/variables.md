# Переменные для Docker и мониторинга

Переменные приложения описаны в [Переменные окружения](../../environments.md). Здесь только те,
что нужны для Docker и мониторинга. Значения задаются в файле `.env`, в окружении
или в параметрах запуска (они перезаписывают `.env`).

| Переменная                                | Значение по умолчанию | Описание                                       |
|-------------------------------------------|-----------------------|------------------------------------------------|
| `_DOCKER_CONTAINER_INTERNAL_DB_PORT`      | `5432`                | Внутренний порт БД в контейнере                |
| `_DOCKER_CONTAINER_INTERNAL_APP_PORT`     | `8080`                | Внутренний порт приложения в контейнере        |
| `_DOCKER_CONTAINER_INTERNAL_GRAFANA_PORT` | `3000`                | Внутренний порт Grafana в контейнере           |
| `GRAFANA_PORT`                            |                       | Порт, на котором Grafana доступна локально     |
| `GRAFANA_ADMIN_USER`                      |                       | Логин администратора Grafana                   |
| `GRAFANA_ADMIN_PASSWORD`                  |                       | Пароль администратора Grafana                  |
| `APP_LOGS_SOURCE`                         |                       | Откуда Alloy читает логи приложения (см. ниже) |

`DB_HOST` в Docker не используется: вместо него в `docker-compose.app.yml` указано имя контейнера БД.

## `APP_LOGS_SOURCE`

Обязательна при запуске `docker-compose.monitoring.yml`, пустое значение вызывает ошибку.

| Значение          | Когда использовать                                                                    |
|-------------------|---------------------------------------------------------------------------------------|
| `./logs`          | Приложение запущено локально (не в Docker): Alloy читает папку `logs` в корне проекта |
| `school_app_logs` | Приложение запущено в Docker: Alloy читает том с логами приложения                    |

В `.env` переменная оставлена пустой, значение задаётся при запуске
(см. [Проект локально + мониторинг в Docker](../run/localWithMonitoringRun.md) и
[Проект в Docker + мониторинг в Docker](../run/dockerWithMonitoringRun.md)).
В конфигурации запуска IDEA значение указывается в поле Environment variables.
